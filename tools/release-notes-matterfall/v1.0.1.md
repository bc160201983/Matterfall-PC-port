**Matterfall** (PS4, CUSA02475) PC port by **BilalReloaded**
([YouTube](https://www.youtube.com/@BilalReloaded/videos), [GitHub](https://github.com/bc160201983)).

Native 1440p and 4K output, a fix for crashes and 30 FPS at high resolutions, and an automatic
shader cache refresh. Download **Matterfall-windows.zip** below and extract it over your 1.0.0
folder (your settings and saves are kept). No game files are included.

## New: native 1440p and 4K output

Launcher -> Display -> **Output resolution**: 1080p (PS4), 1440p or 4K. The whole game (3D,
menus, HUD) is drawn at that size; this unlocks the game's own PS4 Pro 4K mode. Render scale
(Graphics) is now a percentage of the output resolution. On a 4K screen, 4K output at 100% is the
sharpest choice.

Measured on an RTX 5080 at 4K output, 100%, Ultra: 60 FPS in the level.

## Fixed

- **30 FPS and a crash at high render scales** (for example 1440p output at 200%, which draws
  5120x2880). The game's own graphics memory, a fixed 2.8 GB on PS4, ran out. It now grows with
  the resolution you choose, and the game's main memory stays at its PS4 size. The game's
  graphics memory cannot go above 4 GB, so above 4K at 100% (or 1440p at 167%) the launcher uses
  the highest render scale that fits and says so.
- **Shader cache from another build was reused.** The cache now records the build and the
  shader settings it was made with; the cache from 1.0.0 is cleared once on the first start
  (expect a few short hitches while shaders compile again).

## Known issues

- **Ultra: lit surfaces sometimes render black** (title screen and levels). It does not happen
  every start and could not yet be reproduced reliably. If you see it, use **High**, or restart
  the game.
- A rare crash in the NVIDIA driver at startup while cached shaders load in the background
  (also in 1.0.0). Start again if it happens.
- The game checks its save about every 15 seconds, which can show as a short hitch.
