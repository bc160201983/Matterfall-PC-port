**Matterfall** (PS4, CUSA02475) PC port by **BilalReloaded**
([YouTube](https://www.youtube.com/@BilalReloaded/videos), [GitHub](https://github.com/bc160201983)).

Two crash fixes. Download **Matterfall-windows.zip** below and extract it over your
folder (settings and saves are kept). No game files are included.

## Fixed

- **Random "Ran out of memory" crash** (the game asked for 15-30 GB at once, also reported on PS4
  emulators). Unreal Engine reads its game package from several threads at once; on Windows a
  positioned read moves the file's shared position, so two overlapping reads could read the wrong
  bytes, and a garbage item count became a huge allocation. Every file read, write and seek now
  goes through one lock per file.
- **Crash at start in the threading library** (libwinpthread). The game can destroy a lock while
  another thread is still leaving it; destroyed locks are now kept for a while before they are
  freed, as in the MediEvil port.

Tested: two 5-minute runs in level 1-1 at 4K output, Ultra, with no crash (about 58 FPS on
average, an RTX 5080).

## Known issues

- Ultra: lit surfaces sometimes render black. Use High or restart the game if you see it.
- The game checks its save about every 15 seconds, which can show as a short hitch.
