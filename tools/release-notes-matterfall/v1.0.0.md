**Matterfall** (PS4, CUSA02475) PC port by **BilalReloaded**
([YouTube](https://www.youtube.com/@BilalReloaded/videos), [GitHub](https://github.com/bc160201983)).

First release. The PS4 game's own code runs natively on Windows; a runtime replaces the PS4
system libraries and a Vulkan renderer runs the PS4 graphics. **No game files are included:** you
need your own copy of Matterfall (an unpacked CUSA02475 folder or a fake PKG; update 1.01 is
recommended).

## Install

1. Download **Matterfall-windows.zip** below and extract it anywhere.
2. Start **Matterfall Launcher.exe**, choose your game folder (or **Install from PKG**), press
   **PLAY**.

Needs Windows 10/11 64-bit, a Haswell-or-newer Intel CPU or any Ryzen, a Vulkan 1.3 GPU and about
6 GB of free RAM.

## What works

- Intro movies, menus, saving and gameplay at 60 FPS. Tested in level 1-1 for 36 minutes with no
  crash and no memory growth: about 5.5 GB of RAM (the PS4 game's own memory budget) and 2 GB of
  video memory, flat over the whole session.
- Audio, controllers (DualSense, DualShock 4, Xbox and others) and keyboard and mouse, all
  remappable.
- **Correct sky lighting.** The game reads a small sky-light table back from the GPU; other PS4
  emulators give it garbage there. The port writes the GPU's result back so the game reads real
  values.
- Fixes the "Ran out of memory allocating 34359803904 bytes" crash that stops the game on PS4
  emulators: a URL helper of the PS4 system left a size unset, and the game allocated whatever was
  there.
- Offline: PSN features (leaderboards, friends, store) answer as "signed out".

## Settings

- Quality presets Low / Medium / Console (the PS4's own) / High / Ultra, and every setting on its
  own: render scale 50% to 200% (the PS4 draws at 84%), shadows (maps up to 4096), ambient
  occlusion, reflections, view distance, level of detail, foliage, effects, post-processing,
  detail, textures, anisotropic filtering, motion blur, depth of field, lens flares, chromatic
  aberration, eye adaptation, anti-aliasing, sharpening.
- Windowed, borderless or fullscreen; VSync; FPS counter; FSR 1.
- Frame limits 30 to 240 and "half display refresh"; engine frame rate above 60 is experimental.
- Shader cache kept between runs with background warm-up: the second start compiled 18 shaders in
  the first 200 s instead of 150.

## Known issues

- The output window is 1080p; higher render scales (up to 200%, 4K internally) are downscaled to
  it.
- The game checks its save about every 15 seconds, which can show as a short hitch.
- There is no "unlimited" frame rate in this version: without a limit the game twice failed with a
  huge memory request at the intro. Use a limit (up to 240).
