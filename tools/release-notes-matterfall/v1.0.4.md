**Matterfall** (PS4, CUSA02475) PC port by **BilalReloaded**
([YouTube](https://www.youtube.com/@BilalReloaded/videos), [GitHub](https://github.com/bc160201983)).

Download **Matterfall-windows.zip** below and extract it over your folder (settings and saves are
kept). No game files are included.

## Fixed

- **Crash after the intro on a second start, with a PC freeze on AMD** (issue #2: GPU page fault,
  "Device lost", fine after deleting the cache). The saved shaders now load before the game starts
  (a loading screen of a few seconds; about 1-3 s for this game) instead of on background threads
  while the game starts its own graphics. No extra hitches while playing. The old behaviour stays
  available: launcher -> Performance -> **Load the shader cache while the game starts**.

## Known issues

- A rare "Ran out of memory allocating 28387590144 bytes" crash a few seconds after a level loads,
  seen with high settings (Ultra, high render scale). Being investigated. If it happens, please
  attach `launcher-last-run.log` to issue #1, and tell us your settings.
- Ultra: lit surfaces sometimes render black. Use High or restart the game if you see it.
